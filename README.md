# Athlete ID 🚀

**The Future of Sports is Digital**

Athlete ID is a multi-sided platform that addresses a critical challenge in the sports industry: **lack of visibility and access for athletes**.

## 🎯 Platform Overview

Athlete ID connects the entire sports ecosystem in one seamless platform:

### Athletes 🏃
- Create comprehensive digital profiles
- Showcase achievements, stats, and highlight videos
- Apply directly to trials, tournaments, and events

### Organizations 🏢
- Host trials, tournaments, and scouting events
- Discover and recruit talent efficiently through advanced search and filtering

### Brands 🏷️ (via Athlete ID Brand Portal)
- Request platform approval and receive verified access with secure sign-in codes
- Manage products in the dedicated marketplace
- Track orders and analytics

## 💡 Problem & Solution

**The Challenge**: Today, sports success often depends on connections rather than capability.

**Our Solution**: Athlete ID makes talent **discoverable, accessible, and scalable** by creating a centralized digital hub for the entire sports ecosystem.

## ⚙️ Hackathon MVP Features

- Athlete profile creation with media uploads (Cloudinary integration)
- Event and trial hosting system
- Streamlined application workflow
- Brand marketplace portal
- Intuitive dashboard experiences for all user types

## 🛠 Tech Stack

| Component | Technology |
|-----------|------------|
| **Frontend** | Next.js + Tailwind CSS |
| **Backend** | Supabase (Auth, Database, Storage) |
| **Media** | Cloudinary |
| **Hosting** | Vercel |

## 🚀 Quick Start

1. Clone the repository
```bash
git clone https://github.com/yourusername/athlete-id.git
cd athlete-id
```

2. Install dependencies
```bash
npm install
```

3. Set up environment variables (Supabase, Cloudinary keys)
```bash
cp .env.example .env.local
```

4. Run the development server
```bash
npm run dev
```
